# odin-etch-a-sketch

This program is a web browser implementation between a sketchpad and an Etch-A-Sketch.

The web browser will contain a box where the user is able to point, click, hold, and drag the cursor in order to draw a line. There will be the option to pick the color you want to sketch with.

At the end of this project I will have learned how to create a website with HTML, CSS, Javascript, with a heavy focus on Javascript's ability to manipulate the DOM. I will have a better understanding of utilizing event listeners and adding and modifying elements all within Javascript.
